# 企业股权健康度评估 · 规则说明

这份说明写的是系统现在用的打分规则。想改题目、分数、评语，告诉开发助手改哪一条就行。

## 客户要填什么

**基础资料（全部必填，电邮除外）**
企业名称、联系人姓名、手机号码、电邮、行业、主要营业地区、年营业额、成立年限、员工人数、股东人数。

- 手机号码只接受马来西亚号码（012-345 6789 或 +60 12-345 6789 都可以）。
- 员工人数 1–100,000，股东人数 1–200，只能填整数。
- 营业额、年限用下拉选择，不会出现负数或乱填。

**20 道选择题，分 5 个方面，每个方面 4 题，全部必答。**

## 怎么打分

1. 每题 4 个选项，分别得 **10 / 7 / 3 / 0 分**。
2. 每个方面满分 40 分，换算成 100 分制（得分 ÷ 40 × 100）。
3. 综合得分 = 五个方面按权重加权：

| 方面 | 权重 | 看什么 |
|---|---|---|
| 股权结构 | 25% | 控制权是否稳固、股东权责是否清晰 |
| 公司治理 | 20% | 决策机制、公司架构、对老板个人的依赖 |
| 财务合规 | 20% | 公私分账、报表、税务、是否清楚利润和估值 |
| 团队激励 | 20% | 核心人才激励、流失、考核、第二梯队 |
| 资本规划 | 15% | 融资扩张计划、传承安排、引资准备、估值认知 |

## 评级与推荐

| 综合得分 | 等级 | 报告标题 | 推荐的下一步 |
|---|---|---|---|
| 80–100 | A | 股权健康 · 具备资本化基础 | 私董会陪跑服务 + 资本规划咨询 |
| 60–79 | B | 基础尚可 · 存在关键隐患 | 全赢资本 3 天线下股权课 |
| 0–59 | C | 风险偏高 · 需优先梳理 | 3 小时股权 Preview 课 + 1 对 1 股权诊断 |

## 建议怎么自动出现

- 某个方面 **低于 60 分** → 标为「优先处理」，插入 3 条重点改善建议。
- **60–79 分** → 标为「持续优化」，插入 2 条优化建议。
- **80 分以上** → 标为「保持」，一句维持建议。
- 任何一题选了 **3 分或 0 分** 的答案 → 在该方面下面插入这一题的专项提醒，并写出客户当时选了什么。
- 建议按分数从低到高排，最需要处理的放最前面。

## 评语不会自相矛盾

- 「核心优势」只列 75 分以上的方面；没有的话会如实说「暂无突出项」。
- 「主要短板」只列 60 分以下的方面；没有的话会说「没有明显短板」。
- 五个方面全部满分、全部 0 分、或分数很接近，都有专门的说法，已逐一测试过。

## 报告结构（A4）

1. 封面：报告名称、企业名称、评估日期、报告编号（例如 WK-20261024-AB3K）
2. 评估摘要：综合得分、等级、总评、企业资料、核心优势与短板、建议的下一步
3. 详细维度分析：雷达图、各方面得分与权重
4. 改进建议与方案
5. 附录：20 题作答明细
6. 封底：公司资料、免责声明

## 资料安全

客户填的资料只在他自己的浏览器里计算，不会传到任何地方，也不会保存。点「返回修改」或关掉网页，报告就消失。
